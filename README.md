# Practice by Numbers Field Guide

An onboarding reference on Practice by Numbers (PBN), a US dental practice operations
platform: the company, its eight product suites, how the PMS integration works, the
dental software market it sits in, and a five-week learning path.

Compiled September 2026 from practicenumbers.com, help.practicenumbers.com, and primary
industry sources (Open Dental / NexHealth / Henry Schein One developer docs, HHS, eCFR,
ADA, NADP).

Unsourced PBN marketing figures are labelled as such throughout. Benchmark ranges in the
KPI section are industry rules of thumb, not statistics. Verify before repeating externally.

Single self-contained HTML file, no build step. Served from `index.html` via GitHub Pages.
